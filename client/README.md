# Portfolio — client

React + TypeScript + Vite frontend. See the [repo root README](../README.md) for the full project overview (live URL, sections, tech stack, backend).

```bash
npm install
npm run dev      # local dev server
npm run build    # tsc -b && vite build
```

`api/contact.ts` is deployed alongside this app as a Vercel serverless function — no separate deploy step needed.
